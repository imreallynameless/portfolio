# My Portfolio & Playground

This repository contains my personal website and associated backend services for the interactive playground features.

## 🏗 Repository Structure

```
├── my-project/           # Main React website
├── playground-backend/   # Backend services for playground features
├── node_modules/         # Root dependencies
└── package.json         # Root package configuration
```

## 🌐 Main Website (`my-project/`)

My modern React-based personal portfolio website built with:
- **React 18** with modern hooks and patterns
- **React Router** for client-side navigation
- **Styled Components** for component styling
- **Material-UI Icons** for iconography
- **Responsive Design** with mobile-first approach

### Features
- **Portfolio Pages**: Home, About, Projects, Resume
- **Interactive Playground**: Various demos and integrations
- **Performance Optimized**: Lazy loading, image optimization, code splitting
- **Accessible**: Proper ARIA labels, semantic HTML, keyboard navigation

[📖 View Website Documentation](./my-project/README.md)

## ⚡ Backend Services (`playground-backend/`)

Organized collection of backend services that power my playground features:

### 🔧 APIs
- **Spotify API** (Python): Current playing track and user data
- **Custom integrations** for various playground features

### ⚙️ Workers  
- **Strava Worker** (Cloudflare): Activity data fetching and caching
- **TFT Worker** (Cloudflare): Teamfight Tactics match history
- **Optimized variants** for better performance

### 🎮 Demos
- **Spotify Profile Demo**: TypeScript/Vite demonstration app
- **Development tools** for testing integrations

### 📚 Documentation
- **Setup guides** for each service
- **API documentation** and configuration

[📖 View Backend Documentation](./playground-backend/README.md)
